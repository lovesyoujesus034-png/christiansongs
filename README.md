# ChristianSongs by Augustin Vetha Priyan

A static GitHub Pages website for Christian songs.

## Included
- YouTube video embed
- Lyrics
- Chords
- Keyboard notes / notes image
- PDF viewer and link
- Search
- Key transpose buttons
- Church information
- Pastor placeholder for adding later
- Report / AI Reply demo
- Copyright footer

## Add a song
Edit `songs.js`.

Put images in `assets/notes/` and PDFs in `assets/pdf/`, then use paths such as:
`assets/notes/song1.jpg`
`assets/pdf/song1.pdf`

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files and folders.
3. Open Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/ (root)`.
6. Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Real AI
GitHub Pages is static. For real AI replies, use a secure backend/serverless function and keep the API key on the server, not in `script.js`.
